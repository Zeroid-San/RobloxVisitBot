What works here

This website is a functional static dashboard. Navigation, theme switching, browser health checks, form validation, and local configuration persistence work directly in the browser.

What remains local

The original main.py is a Windows application that uses local Roblox files, Windows APIs, processes, and authentication cookies. A normal browser cannot safely or directly replace those capabilities.

Security

Never paste Roblox authentication cookies, passwords, or API secrets into this website or its JavaScript. The dashboard intentionally keeps cookie handling disabled.
