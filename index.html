Project notes

What is functional

Navigation, settings persistence, validation, live clock, health checks, monitor state, session timer, activity logging, and responsive UI all run in the browser.

What stays local

The original Python application uses Windows APIs, Roblox client files, processes, and authentication cookies. This public dashboard intentionally does not handle those credentials or control Roblox clients.

Security

Never place Roblox authentication cookies, passwords, or private API keys in this website or client-side JavaScript.
